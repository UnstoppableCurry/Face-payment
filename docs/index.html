README 记载的四段流水线

下列步骤来自仓库 README 的「项目架构」，并对照目录中的实现文件。方框只说明顺序，不代表本站可以调用这些网络。

  1. 1

    人脸检测

    用目标框锁定人脸。实现目录：yoloV3 人脸检测/，含 Yolov3 与 Yolov3Tiny。

  2. 2

    108 关键点

    做人脸矫正、年龄与性别；README 还提到可用眼部关键点横纵比做活体思路。目录：resnet 108人脸关键点/。

  3. 3

    姿态门控

    回归欧拉角 pitch / yaw / roll；README 写明角度不符合预期时不做身份校验。目录：resnet34 姿态检测/。

  4. 4

    ArcFace 识别

    一对多比对。作者在 README 自述：约十万分之一误检率时通过准确率 50%。目录：ArcFace/。
