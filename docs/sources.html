源码与 README 点名的上游 / 第三方

  • YOLOv3 系实现：yoloV3 人脸检测/test.py 注释指向 ultralytics/yolov3 与 TencentYoutuResearch/ObjectDetection-OneStageDet。util/utils.py 标注 Object-Detection-Metrics、py-faster-rcnn 等片段来源。
  • 作者推荐的训练教程：deep-learning-for-image-processing / yolov3_spp。这是上游教程，不是本仓库子模块。
  • ResNet / ImageNet 权重：关键点与姿态 model.py 使用 PyTorch 官方 resnet18–resnet152 URL。骨干网络来自 He et al. 的 ResNet 一族。
  • Wing Loss：resnet 108人脸关键点/loss.py 实现 README 所述的分段对数 / L1 形式。
  • ArcFace / SE-IR：角度间隔损失与 SEModule 对应 ArcFace、SENet 一类方法；本目录是学习向实现，不是官方 InsightFace 发行包。
  • 关键点脚本署名：predict.py、inference.py、data_agu.py 等页眉写 Author: Eric.Lee，按文件内注释视为上游或共同来源，不改成「本展示页原创」。
  • 点名但未随仓库提供的数据：README 提到 yolo_widerface_open_train、WFLW、wiki_crop_face_multi_task、face_euler_angle_datasets 以及 8 人自采 1:N 集。本站不镜像这些数据。

刻意没有搬进本站的 README 插图

README 里还有大量 user-images.githubusercontent.com 图：YOLO 结构、学习率曲线、Wing Loss 公式表、姿态示意、孪生网络与 FRR-FAR 曲线等。其中不少看起来像论文或教程截图。本站只核验并收录了首张 user-images 配图，以及仓库内的 ArcFace/loss.png，避免把未逐张授权说明的第三方图册做成「项目相册」。
